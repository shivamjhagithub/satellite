# Test data (Phase 50)

This folder will hold **synthetic GeoTIFFs** with known properties so geospatial tests do not need real satellite files.

Planned files (not generated in Phase 1):

| File | Purpose |
|---|---|
| `same_grid.tif` | Control raster on a known grid |
| `different_crs.tif` | Same geography, different CRS |
| `different_resolution.tif` | Same CRS, different pixel size |
| `shifted_grid.tif` | Same CRS/resolution, offset origin |
| `no_overlap.tif` | Disjoint bounds |
| `nodata.tif` | Explicit NoData values |

Do not commit large real imagery. Keep fixtures small and generated by a script in a later phase.
